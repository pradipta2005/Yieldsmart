# YieldSmart API Backend

FastAPI backend for the YieldSmart Smart Farming Platform, hosted on Hugging Face Spaces.

## Live API Endpoints:
- **Health Check**: `/api/health`
- **Dashboard**: `/api/dashboard?city=Kolkata`
- **Auth Signup**: `/api/auth/signup`
- **Auth Signin**: `/api/auth/signin`
- **Disease Scan**: `/api/detect-disease`
- **History**: `/api/history`
